# Rafael Limongi — Portfólio

Portfólio pessoal, desenvolvido com React + Vite + TypeScript + Tailwind CSS v4.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Deploy: Vercel
